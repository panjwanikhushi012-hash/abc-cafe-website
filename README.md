# ABC Café Website

A responsive luxury/modern café website demo for ABC Café, Karachi.

## Files

- `index.html` — main website
- `style.css` — design and responsive styles
- `script.js` — mobile navigation and reveal animations

## Before publishing

Replace/verify:
- WhatsApp number
- Instagram handle
- Exact address
- Opening hours
- Menu items/prices
- Café-owned photos

The current food/interior images are external Unsplash demo images and should be replaced with the client's licensed/owned photography before final delivery.

## Deploy with GitHub + Vercel

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`.
3. Push/commit the files.
4. Import the repository into Vercel.
5. Deploy.
6. Vercel will provide a temporary `.vercel.app` URL.
7. After client approval, connect the client's custom domain in Vercel.

No build command is required for this static HTML/CSS/JS version.
